# Al Mostafaa Academy Website

Responsive one-page website for Al Mostafaa Academy, built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — visual design and responsive layout
- `script.js` — mobile navigation, back-to-top button, and demo enquiry form
- `assets/mosque-background.jpg` — mosque image supplied for the hero and supporting imagery

## Run locally
Open `index.html` in a browser. For a better development experience, use VS Code with the Live Server extension.

## Before publishing
1. Replace the sample reviews with real, permission-approved testimonials.
2. Add the academy's WhatsApp number in `script.js` as international digits only, without `+` or spaces.
3. Add the official phone number and email in `index.html`.
4. Replace the current Font Awesome placeholder kit URL in `index.html` with a valid kit, or switch the icons to a public CDN stylesheet.
5. Confirm the exact academy map pin and update the map embed if needed.
6. Connect the enquiry form to a backend or form provider if you want submissions stored online.

The site uses Google Fonts and map embeds, which require an internet connection.
